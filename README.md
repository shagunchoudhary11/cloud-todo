# Cloud To-Do App

A real-time to-do app built with Next.js and Firebase.

**Live Demo:** https://cloud-todo-app-brown.vercel.app	

## Features
- Email/password signup and login (Firebase Authentication)
- Add, edit, complete and delete tasks
- Real-time sync with Cloud Firestore
- Per-user data protected by Firestore security rules

## Tech Stack
- Next.js (App Router, TypeScript)
- Firebase Authentication
- Cloud Firestore
- Deployed on Vercel

## Run Locally
1. Clone the repo and run `npm install`
2. Add your Firebase web config in `lib/firebase.ts`
3. Run `npm run dev`
4. Open http://localhost:3000
